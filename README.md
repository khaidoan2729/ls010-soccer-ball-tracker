# ls010-soccer-ball-tracker

This project is an affordable, embedded soccer analytics system built as an engineering proof of concept for UBC Thunderbirds, in partnership with Joho Tek. It detects and tracks a soccer ball from a single camera feed or recorded footage, running core processing directly on a portable edge device (such as an NVIDIA Jetson or a Raspberry Pi with an AI accelerator) instead of relying on the cloud. From the tracked ball, the system produces basic analytics for coaches and analysts: ball position, trajectory, movement direction, approximate speed, time spent in field zones, and possession-related trends, all shown on a simple dashboard alongside live device performance. The goal is to measure what low-cost hardware can actually deliver, reporting frame rate, latency, detection accuracy, power, memory, thermal behavior, and cost. It is a feasibility prototype, not a replacement for professional multi-camera sports-analytics platforms, and its limitations are documented openly.
